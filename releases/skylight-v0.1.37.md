# Astra 0.1.37 更新内容

## 本次更新

- 同步上游 v0.4.21 的功能更新与修复，保留 Astra 本地布局、图标、用量浮窗和编辑器交互。
- 紧凑布局的顶部项目标签新增右键菜单，与经典布局的更多菜单共用置顶、在 Finder 中显示、重命名和删除操作。删除仍需二次确认，右键未选中的项目不会切换当前页面。
- 项目菜单支持 Shift+F10 打开、方向键选择和 Esc 关闭；重命名完成后恢复到对应项目入口。
- 修复样式加载顺序导致的设置页布局异常，恢复本地主题的覆盖顺序。
- 修复顶栏通知与待处理入口错位，以及 Git 当前分支圆点被拉长的问题。

## 如何升级

从 [Astra 发布页](https://github.com/skylight-f/zeus/releases/tag/skylight-v0.1.37) 下载 Astra-0.1.37-arm64.dmg，退出 Astra 后安装。

Homebrew：`brew upgrade --cask skylight-f/tap/astra`。

## 系统要求与已知限制

面向 Apple Silicon Mac，要求 macOS 13 或更高版本。签名、公证及自动安装能力以本次更新清单和应用检查结果为准。

## 发布验证

本地已完成静态检查、macOS 构建及实际界面验收，覆盖紧凑与经典布局、设置页、Git 导航和项目菜单。公开发布须通过当前候选的 CI、安装包与清单校验；结果见同一提交的 GitHub Actions 记录。
